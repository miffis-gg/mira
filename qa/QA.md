Для ускорения первого кадра секции ниже hero используют `content-visibility:auto` с сохранением размеров; браузеры без поддержки показывают обычный поток страницы.

## Покрытие

- Viewport: 390, 768, 1024, 1280, 1440 px; проверка горизонтального переполнения, единственного H1, загрузки видимых фотографий и ошибок JS.
- Все пять фильтров каталога и галереи, счётчики, сохранение услуги при смене направления, уведомление о выбранной услуге вне фильтра.
- Несовместимый специалист сбрасывается при смене услуги. Цены, длительность и совместимость вычисляются из единых данных.
- Запись: обязательный выбор услуги и специалиста, даты и времени; отсутствие слотов у Алисы в последнюю демонстрационную дату; корректный путь до успеха и полный reset.
- Валидация: пустые поля, однобуквенное и 61-символьное имя, неполный телефон, 301 символ пожелания, отсутствие подтверждения; фокус на первой ошибке. Принимается вставленный телефон `8 (900) 123-45-67`.
- Возврат к контактам сохраняет значения; итог маскирует телефон. Двойное подтверждение не создаёт повторного сценария.
- Сброс во время локальной задержки отменяет таймер; прежнее подтверждение не меняет новый выбор.
- Во время подтверждения нет сетевых запросов. После успеха localStorage/sessionStorage пусты, cookie отсутствует.
- Клавиатурная запись от выбора услуги до успеха. Skip-link, mobile menu, Escape и возврат фокуса, FAQ, radio/checkbox/submit.
- Mobile dock появляется после выбора и скрывается рядом с FAQ, формой и footer; номинал сертификата и диапазон собственной суммы работают.
- `prefers-reduced-motion` отключает перемещение. Удвоение реальных computed font-size до 200% не создаёт горизонтальной прокрутки на 390 px.
- Нейтральный fallback при недоступной второстепенной фотографии.

## Визуальные доказательства

`screenshots/mira-390.png`, `mira-768.png`, `mira-1024.png`, `mira-1280.png`, `mira-1440.png` — итоговые полные страницы. Длинный mobile PNG собран из последовательных viewport-снимков, чтобы избежать артефакта fullPage-растеризатора на высоте более 16 384 px. Перед снимками ожидаются шрифты и lazy-фотографии; оптимизация `content-visibility` временно раскрывается только для полного capture.

Дополнительные crop-файлы предназначены для осмотра деталей. Демонстрационные фотографии проверены по контактному листу, лицам, рукам, инструментам и кадрированию. Источники и лицензия каждого кадра: `public/images/sources.json`.

Визуальная система сверена с исходным DESIGN.md: локальные Prata и Onest; фарфор, минеральный и сливовый; редакционный hero; постоянные числовые колонки прайса; управляемая галерея; последовательная мобильная композиция. Утверждённые AGENTS.md, DESIGN.md и STRUCTURE.md сохранены.

## Границы

Это браузерная эмуляция viewport, а не испытание на физическом телефоне. Экранная клавиатура iOS/Android, реальные safe-area устройства, VoiceOver/NVDA, Safari и Firefox отдельно не проверялись. Lighthouse и axe не заменяют ручную экспертизу всех требований WCAG. Сертификат, расписание, контакты и профили остаются демонстрационными.

## Повторение

```sh
npm ci
npm run typecheck
npm run build
node scripts/run-browser-checks.mjs
node scripts/lighthouse-check.mjs
```

Lighthouse-скрипт использует установленный Edge по стандартному Windows-пути. Playwright закрывает созданный preview после проверок. Для другого окружения измените путь браузера/канал в конфигурации.
